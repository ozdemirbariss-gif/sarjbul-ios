# EPDK-only değişikliği doğrulaması

8 Ekim 2026. Bu kayıt teknik doğrulamadır; sağlayıcı izni, backend dağıtımı veya mağaza yayını değildir. EPDK yazılı ticari kullanım/yeniden dağıtım izni bulunmadığı için `commercialDataUseApproved=false` kalır.

- Ham EPDK yanıtından 13.129 halka açık istasyon / 36.391 soket / 61 tile üretildi. Veri saflığı ve tüm tile hash/sayıları `python3 Scripts/validate_data_rights.py --epdk-only` ile doğrulandı; envanterde ana ve katkı kaynakları yalnızca `epdk`. [Kaynak/hash/kimlik değişiklikleri](EPDK_ONLY_MIGRATION.md).
- Python: `python3 -m unittest discover -s Scripts/tests -q` — **35 test başarılı**. Yalnızca EPDK normalizasyonu, eski alan/kimliklerin taşınmaması, özel/kaldırılmış kayıtların elenmesi, hata/eksik yanıt ve kalite eşikleri, kaynak saflığı, kanıt/hash/süre/kapsam ve plist bayrağıyla izin gate'ini aşamama dahil. Builder'ın başarılı yayın yolu sadece açıkça test olarak etiketlenen fixture izinleriyle doğrulandı; gerçek EPDK izni sayılmaz.
- Çekirdek: `swift test --scratch-path /tmp/sarjbul-epdk-only-core` — **87 test / 15 suite başarılı**. Gerçek paketin hash/decoding/arama doğrulaması; EPDK-only cache'in yeniden yüklenmesi; eski cache'ten çevrimdışı bundle'a dönüş; eski uzak manifest ve gizlenmiş ikincil kaynak/ID/alanların reddi dahil.
- iOS: iPhone 17 Pro / iOS 26.5 simülatöründe **68 test başarılı, 0 başarısız, 0 atlanan**. `SarjBulUnitTests` ve `AppSmokeUITests/testBundledStationCatalogCreatesRoute`, `testStationStoryImageOpensShareSheet`. Gerçek uygulama composition root'undan yalnızca EPDK bundle'ı yükleme, eski cache'i kişisel dosyaları silmeden kaldırma ve eski tam istasyon içeren önerileri temizleme testleri dahil. Sonuç: `/tmp/SarjBulEPDKOnlyTests.xcresult`.
- `xcodebuild build-for-testing`, strict SwiftLint, plist lint, `validate_release.py` kaynak kontrolü ve `git diff --check` başarılı. Mevcut yerel bağımlılık çözümlemesi korundu; üretim binary'sinin SDK privacy manifestleri yayın kontrolünde tekrar karşılaştırılmalı.
- Testin ürettiği paylaşım görseli açılıp incelendi: native Apple “Harita” bildirimi görünür; EPDK dipnotu ve epdk.gov.tr okunur. README görseli ve [çekim kaydı](screenshots/station-story.capture.json) güncellendi. Gerçek cihaz adres araması/arka plan yaşam döngüsü kontrolleri [cihaz planında](DEVICE_TEST_PLAN.md) bekler.
- Sağlayıcı gate'i **beklendiği gibi yalnızca `epdk=pending_permission` nedeniyle başarısız**. ChargeIQ/OSM kaldırma kanıtları ve Apple/Open-Meteo kanıt hash'leri geçerlidir. Eski kamuya açık birleşik kopyaların hakları kapatılmış sayılmaz.
- `validate_release.py --production` ayrıca bu çalışma alanında bulunmayan `AppConfig.plist` ve `GoogleService-Info.plist` dosyalarını bildirir. Günlük workflow izin gate'i geçmeden sorgu/yayın yapmaz. Özel canonical depo/anahtar bağımlılığı kaldırıldı; tam ham yanıttaki özel istasyonlar Actions artifact'ına veya uygulamaya yayımlanmaz.

İşletmeci lisans snapshot'ı EPDK kaynaklı mevcut içerikle korunmuştur; ayrıca yenilenmemiştir. Kimlik değişimi nedeniyle eski üçüncü taraf ID'sine bağlı favori/son rota/paylaşım bağlantıları otomatik taşınmaz; kişisel veri silinmez. Git geçmişi yeniden yazılmamış, dış projeler ve eski sürümler geri çekilmemiştir.
