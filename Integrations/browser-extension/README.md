# SarjBul Browser Extension

Chrome/Edge üzerinde uygulamayı açmadan yakın, hızlı veya ekonomik istasyon bulur.

1. `chrome://extensions` sayfasında Developer mode'u aç.
2. `Load unpacked` ile bu klasörü seç.
3. Uzantının ayarlarında dağıtılan `browserCommand` URL'sini ve `BROWSER_EXTENSION_KEY` değerini gir.

Konum yalnızca sorgu sırasında gateway'e gönderilir; uzantı konumu depolamaz.
